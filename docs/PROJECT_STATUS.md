# Project Status

**Status: Archived research artifact**

This repository is retained as an educational/research reference around the paper *Fast and Fair Randomized Wait-Free Locks*.

## What is preserved

- attribution and paper reference;
- research questions and evaluation requirements;
- limitations of translating formal algorithmic guarantees into Python/runtime observations.

## What is not claimed

The current repository does not contain a completed executable implementation, reproducible correctness suite, benchmark baseline, formal proof artifact, or production-ready synchronization primitive.

## Deferred work

The previously proposed correctness and benchmark milestone is closed as not planned for the current cycle. If the project is resumed, that milestone should begin with executable code, deterministic seeds, machine-readable raw results, explicit environment metadata, and tests for observable correctness properties.

No historical limitation or deferred item should be rewritten as if it had been completed.
